# Security

- No CI/CD. Deploys are manual via Render Blueprint (`render.yaml` with `autoDeployTrigger: 'off'`).
- Secrets are never committed. Local secrets live in gitignored `.env` / `frontend/.env`; production secrets are set as Render env vars (`BOOTSTRAP_ADMIN_EMAIL`, `BOOTSTRAP_ADMIN_PASSWORD`, `GEMINI_API_KEY`, `CLOUDINARY_*`, `JWT_SECRET_KEY` generated by Render).
- Bootstrap admin is created only if the email does not exist; existing passwords are never reset by deploys.
- Report a vulnerability by opening a private issue or contacting the repo owner. Do not post secrets in issues.
